## Review fixes

- Bound formatted snippet output as well as input to 12 KiB. Black can expand a short valid snippet beyond Windows command-line limits; the formatter now warns and runs the original source when output exceeds the budget.
- Keep dynamic launch, messaging, and cancellation responsive while another subagent holds the Python mutation lock. Tool authorization remains enforced.
- Carry cumulative tool-round and delegated-call budgets across reactive notifications. A new independent request receives a fresh budget.
- Correct the new standards and subagent changelog links for both the repository and rendered documentation.
- Run the normal CI workflow for pushes and pull requests targeting both `main` and `0.4.1`.

## Validation

All review findings have regression coverage. The final merged tree passes 139 focused agent/runtime, lifecycle, scope, formatting, packaging-contract, and documentation checks. The review branches also passed 166 formatting-related checks, 93 runtime-related checks, and 101 standards/documentation-related checks. These sets overlap and must not be added together.

Repository-wide Ruff checks pass. Production Mypy checks cover the changed code. The final merged wheel and source distribution build and pass Twine validation. MkDocs renders the standards documentation successfully; existing unrelated link warnings remain outside this milestone's changes.

Full-suite CI runs on the integration branch; inspect the current [Actions results](https://github.com/mlg151/henchman-ai/actions/workflows/ci.yml) before release. Live-provider effectiveness, latency, whole-process memory, and native Windows behavior remain unmeasured by these local checks.

Integration does not publish a release or change the installed version. Release versioning and publication remain separate work.
